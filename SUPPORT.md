# Getting help

- **Questions about using Mohar**: open a [discussion](https://github.com/harshitwandhare/mohar/discussions) or a feature issue if something is missing.
- **Bugs**: open a bug issue with steps to reproduce.
- **Security problems**: report privately through the [Security tab](https://github.com/harshitwandhare/mohar/security/advisories/new). Never in a public issue.

Mohar is maintained by one person in the open. There is no paid support. Replies usually come within a few days.
